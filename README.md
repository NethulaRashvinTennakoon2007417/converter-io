# converter.io

Free, ad-free converter that runs entirely in the browser. Static site, no build step.

Dashboard with search, category filters, pinned tools, drop-a-file-to-find-the-right-tool, usage stats and recent activity (stored in the browser only).

Tools: merge, split, rotate, compress, images to PDF, PDF to images, OCR (English/Sinhala/Tamil), Word to PDF/HTML.

## Deploy
1. Push this folder to a GitHub repo.
2. In Vercel: Add New Project, import the repo, leave all settings as default, Deploy.
